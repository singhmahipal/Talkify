## ✨ Features

- 💬 **Instant Messaging** — Real-time chat with typing indicators & emoji reactions  
- 📹 **Video & Voice Calls** — 1-on-1 and group calls with screen sharing & recording  
- 🔐 **JWT Authentication** — Secure auth, protected routes & persistent sessions  
- 👥 **Friends System** — Add, accept, and manage friends easily  
- 🎨 **32 UI Themes** — Personalize the interface with unique looks  
- ⚙️ **Scalable Stack** — React + Node.js + MongoDB + Stream  
- 🧠 **State Management** — Powered by Zustand + TanStack Query  
- 🚨 **Robust Error Handling** — Validations at both client & server ends  
- 🚀 **Deployment Ready** — Smooth setup for Vercel, Render, or Netlify
